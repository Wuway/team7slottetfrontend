# UC02 – Log ud

| Felt | Beskrivelse |
| :--- | :--- |
| **Use Case ID** | UC02 |
| **Navn** | Log ud |
| **Primær aktør** | Medarbejder |
| **Mål** | Medarbejderen kan logge ud af systemet for at afslutte sin session og sikre, at andre ikke får adgang. |

## Beskrivelse
Medarbejderen kan vælge at logge ud af systemet via en log ud-knap. Når medarbejderen logger ud, afsluttes den aktive session, og systemet returnerer til login-siden.

---

## Tasks
1. **Vælg log ud** (Medarbejderen klikker på log ud-knappen)
2. **Afslut session** (Systemet lukker den aktive brugersession)
3. **Returner til login-side** (Brugeren sendes tilbage til login-siden)
