# UC08 – Oprette og se opgaver/beskeder (Daily Tasks)

| Felt | Beskrivelse |
| :--- | :--- |
| **Use Case ID** | UC08 |
| **Navn** | Oprette og se opgaver/beskeder (Daily Tasks) |
| **Primær aktør** | Medarbejder |
| **Mål** | Medarbejderen kan oprette og se daglige opgaver eller beskeder, så vagtholdet har overblik over dagens aktiviteter. |

## Beskrivelse
Medarbejderen kan oprette opgaver eller beskeder i systemet, som vises på dashboardet som "Daily Tasks". Disse kan indeholde information om praktiske opgaver, påmindelser eller beskeder til næste vagthold. Opgaverne gemmes i systemet og er synlige for alle medarbejdere, hvilket sikrer et fælles overblik over ting, der skal udføres eller videregives.

---

## Tasks

1. **Opret opgave/besked**
   - Medarbejderen kan skrive en ny opgave eller besked direkte i systemet.
2. **Gem opgave**
   - Systemet gemmer opgaven i listen over Daily Tasks for den valgte dag/vagt.
3. **Vis opgaver på dashboard**
   - Opgaver og beskeder gøres synlige for alle medarbejdere i dashboard-oversigten.
4. **Opdatere opgave**
   - Medarbejderen kan rette i indholdet af en eksisterende opgave.
5. **Markere opgave som udført**
   - Brugeren kan markere opgaven som færdig, hvilket visuelt ændrer dens status på dashboardet.
