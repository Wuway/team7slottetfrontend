# UC07 – Ugenotater (Handledag, betaling)

| Felt | Beskrivelse |
| :--- | :--- |
| **Use Case ID** | UC07 |
| **Navn** | Ugenotater |
| **Primær aktør** | Medarbejder |
| **Mål** | Medarbejderen kan registrere og se ugenotater for en beboer, herunder information om handledag og betaling. |

## Beskrivelse
Medarbejderen kan registrere relevante ugenotater for den enkelte beboer. Notaterne kan eksempelvis indeholde information om handledag eller betaling. Notaterne gemmes i systemet og kan vises på dashboardet eller i beboerens oplysninger, så personalet har et fælles overblik over ugens faste opgaver.

---

## Tasks

1. **Åbn ugenotater på beboer**
   - Medarbejderen vælger en beboer og åbner sektionen for ugenotater.
2. **Registrer handledag**
   - Medarbejderen kan tilføje eller opdatere information om, hvornår der skal handles for beboeren.
3. **Registrer betaling**
   - Medarbejderen kan notere oplysninger om status på betaling eller faste udgifter.
4. **Gem ugenotat**
   - Systemet gemmer notatet og knytter det til den valgte beboer.
5. **Vis ugenotater**
   - Ugenotaterne gøres synlige i dashboard-oversigten eller i de detaljerede beboeroplysninger.
